# Instructions for AI Agents

Before making any change to this repository, read these two files in full and
follow them:

- [README.md](README.md): what Ceres is, its frontends, and how to build and
  run it.
- [CONTRIBUTING.md](CONTRIBUTING.md): the commit message convention, the code
  style and formatting tools, and how to run the tests.

In particular, every commit you create must follow the Conventional Commits
format described in `CONTRIBUTING.md` and must carry an `Assisted-by:` footer
naming the tool and, where known, the model (see "AI-Assisted Contributions"
there).
